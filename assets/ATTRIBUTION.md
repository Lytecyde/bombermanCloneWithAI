# Asset Attribution

The tile and sprite art in this folder (`tile_grass.png`, `tile_wall.png`, `tile_wood.png`,
`bomb.png`, `fire.png`, `bomberman.png`) was sourced from the open-source project
**html5-bombergirl** by Matouš Skala (https://github.com/MattSkala/html5-bombergirl,
MIT-licensed code), which in turn credits:

- **Tile Art Batch** by Hyptosis — http://www.newgrounds.com/art/view/hyptosis/tile-art-batch-1
  (public domain / free-to-use tile art, widely redistributed via OpenGameArt.org)

These assets are used here for the "Reverse Bomberman" mode (`bomberman.html` /
`ReverseBomberman.js`).
